# CareerOps Web

Interface web para o sistema de gestão de candidaturas [CareerOps](https://github.com/santifer/career-ops), originalmente construído por Santiago Ferreira.

## 🖥 Preview

> Adicione um print ou GIF da tela aqui

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## ✨ Funcionalidades

- Pipeline Kanban com 5 colunas: Avaliando, Aplicado, Entrevista, Oferta e Rejeitado
- Cards dinâmicos gerados via JavaScript
- Modal de detalhes ao clicar no card
- Filtros por tipo de vaga
- Dark mode com paleta personalizada
- Layout responsivo com scroll horizontal

## 🚀 Como rodar

1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/career-ops-web.git
```

2. Abra o arquivo `telaDashboard.html` no navegador

> Não requer instalação de dependências — projeto 100% frontend.
